    The trench is a communication conduit, ranging from 0 to 65634. Devices with the same trench number can send messages to each other. Receiving a message with a wrong trench number is discarded. On this screen one may configure which trench number is loaded by default.
Default Trench: (0-65534)  
    The device stores communication history on-board, in permanent storage. This allows the device to be unplugged, re-connected to a different host, without the loss of communication data. (For example moving the device connection from smart phone to laptop or from simple power supply to cell phone.) The button below removes all communication history from the current session and from the device's on-board storage. This feature is provided as a privacy measure, it is not needed for normal operation.
