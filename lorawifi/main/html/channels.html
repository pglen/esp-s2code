    The following table describes the LORA 433 MHz channel allocation, recommended by the manufacturer of the device and international standard bodies. In the LORA WiFi product, these values are not enforced, they can be set to arbitrary values. The only criteria is that they are between the device's lower and upper frequency limits. Please note that both the receiver and sender has to be tuned to the same frequency to communicate.
Common recommended platform presets:
LORA Channel Frequency Bandwidth (optional) Scope
1 433.375 MHz 125 kHz Default / Mandatory
2 433.575 MHz 125 kHz Default / Mandatory
3 433.775 MHz 125 kHz Optional / Extension
4 433.975 MHz 125 kHz Optional / Extension
5 434.175 MHz 125 kHz Optional / Extension
6 434.375 MHz 125 kHz Optional / Extension
7 434.575 MHz 125 kHz Optional / Extension
The device's frequency defaults to channel 1. (433.375 MHz).

Bandwidth threshold values:
7.8kHz 10.4kHz 15.6kHz 20.8kHz 31.25kHz 41.7kHz 62.5kHz 125kHz 250kHz 500kHz
The bandwidth configuration will obey the above thresholds, and set according to the limit specified on the above table. For example setting it 40kHz will round it down to 31.32kHz. Set it to 42kHz will round it down ro 41.4kHz.

The device bandwidth defaults to 40kHz.

**Disclaimer: While the 433MHz Band is regulated relatively uniformly across countries, still, the regulations vary somewhat. Always check local spectrum regulations before deploying 433MHz devices.
