The following fields determine the LORA transmit / receive configuration. These configurations must match between the sender and receiver units. The parameters are range contained. The frequency parameter is a floating point number multiplied by megahertz. The bandwidth parameter is a floating point number multiplied by kilohertz. Please note: for communication stability the lowest recommended bandwidth is 40+ kHz. (This is due to the LORA Board's chrystal instability)
