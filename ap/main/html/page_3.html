The following fields determine the LORA transmit / receive configuration. These configurations must match between the sender and receiver units. The parameters are range contained. The frequency parameter is a floating point number multiplied by megahertz. The bandwidth parameter is a floating point number multiplied by kilohertz. Please note for communication stability that the lowest recommended bandwith is 20 kHz.
